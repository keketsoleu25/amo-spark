# Amo Spark & Scent Solutions

Sales-first storefront for Amo Spark, a local cleaning-products and room-diffuser business.

## V1 scope

- Mobile-first landing storefront
- Cleaning product catalogue placeholders
- Room diffuser catalogue placeholders
- About section
- Contact/order CTA
- Brand palette based on Amo Spark green and orange
- Placeholder imagery so real product photos can be dropped in later

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Before launch

Replace placeholder product names, sizes, scents, prices, images and the temporary contact link with Amo Spark's real business details.

## Stack

Next.js 16 · React 19 · TypeScript · Tailwind CSS 4
